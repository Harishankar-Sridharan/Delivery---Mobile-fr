# Actions principales

Le menu des actions principales vous permet de gérer votre profil et de consulter les informations essentielles de l’application. Utilisez cette zone pour personnaliser votre identité et faciliter les transferts entre utilisateurs. Vous obtiendrez un profil personnalisé et une meilleure coordination avec les autres membres de l’équipe.

#### Prise en main

* Compte actif sur l’ **Nomadia Delivery** application mobile.
* Accès à la caméra de l’appareil mobile pour la mise à jour des photos.
* Ouvrez l’application et commencez dans le **tableau de bord** écran.
* Appuyez sur l' **menu à trois lignes** dans le coin supérieur gauche.

<figure><img src="../.gitbook/assets/image (11).png" alt="" width="540"><figcaption></figcaption></figure>

#### Aperçu de la fonctionnalité

* **Logo de l’application**: Affiche votre photo de profil actuelle dans la barre latérale.
* **Numéro de version**: Affiche la version actuelle du logiciel dans le coin supérieur droit.
* **Icône du code QR**: Donne accès à votre code unique pour les opérations de transfert.

<figure><img src="../.gitbook/assets/Media (29).jpg" alt="" width="540"><figcaption></figcaption></figure>

#### Mode d’emploi : mettre à jour l’image de profil

1. Appuyez sur l' **icône de caméra** affichée dans la zone du logo.

<figure><img src="../.gitbook/assets/image (13).png" alt="" width="540"><figcaption></figcaption></figure>

2. Sélectionnez **choisissez une image** pour sélectionner un fichier depuis votre galerie.
3. Sélectionnez **prendre une photo** pour prendre une nouvelle photo avec votre caméra.
4. Terminez les étapes (le bug a été corrigé)
5. Appuyez sur **annuler** pour arrêter l’opération sans effectuer de modifications.

<figure><img src="../.gitbook/assets/Media (30).jpg" alt="" width="540"><figcaption></figcaption></figure>

#### Mode d’emploi : utiliser le code QR pour les transferts

1. Appuyez sur l' **icône de code QR** située à côté du logo.
2. Affichez le **code QR** afin qu’un autre utilisateur le scanne.
3. Appuyez sur l' **flèche de retour** dans le coin supérieur gauche pour quitter.

<figure><img src="../.gitbook/assets/Media (31).jpg" alt="" width="540"><figcaption></figcaption></figure>

#### Conseils de productivité

* 💡 **Transferts personnels**: Partagez votre code QR avec d’autres utilisateurs pour enregistrer un transfert personnel entre les membres de l’équipe.
* ⚠️ **Annuler les modifications**: Appuyez sur **annuler** si vous sélectionnez la mauvaise option de photo afin d’éviter de mettre à jour votre logo par erreur.
