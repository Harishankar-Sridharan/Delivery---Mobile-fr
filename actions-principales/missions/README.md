# Missions

Le **Missions** la section est l’espace de travail central pour gérer les tâches de livraison et de collecte. Elle permet aux utilisateurs de consulter les missions attribuées, de mettre à jour le statut des missions, d’effectuer des actions opérationnelles, de capturer une preuve de livraison et d’achever les missions selon le flux de travail configuré.
