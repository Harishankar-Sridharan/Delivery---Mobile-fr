# Agences

La fonctionnalité Agences vous permet de gérer différents centres opérationnels au sein de Nomadia Delivery. Elle garantit que votre affichage montre des données spécifiques à un emplacement choisi. La sélection d’une agence met à jour votre tableau de bord avec les informations pertinentes pour ce site.

#### Prise en main

* Appareil mobile avec l’application Nomadia Delivery installée.
* Compte utilisateur actif disposant d’autorisations d’accès aux agences.
* Ouvrez l' **Menu des actions principales**.
* Appuyez sur **Agences**

<figure><img src="../../.gitbook/assets/image (134).png" alt="" width="540"><figcaption></figcaption></figure>

#### Aperçu de la fonctionnalité

* **Agences**: Cet écran affiche une liste de tous les emplacements disponibles pour la sélection.
* **Tableau de bord**: Cette interface affiche le nom de l’agence que vous avez actuellement sélectionnée.

#### Mode d'emploi : sélectionner une agence

1. Ouvrez l' **Menu des actions principales**.
2. Faites défiler vers le bas les options du menu.
3. Appuyez sur **Agences**.

<figure><img src="../../.gitbook/assets/image (135).png" alt="" width="540"><figcaption></figcaption></figure>

4. Sélectionnez un nom d’agence dans la liste.

<figure><img src="../../.gitbook/assets/image (136).png" alt="" width="540"><figcaption></figcaption></figure>

\
5\. Consultez le nom de l’agence mis à jour sur le **Tableau de bord**.
