# Compte

Le **Compte** La section contient des paramètres spécifiques à l’utilisateur et des informations sur l’application. À partir de là, les utilisateurs peuvent configurer les paramètres de l’application, gérer les réglages liés à l’agence (le cas échéant), donner leur avis en notant l’application, consulter les dernières mises à jour et accéder aux options liées au compte, comme la déconnexion.
