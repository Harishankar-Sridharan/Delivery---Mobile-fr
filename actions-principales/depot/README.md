# Dépôt

Le **Dépôt** Cette section permet aux utilisateurs de gérer les dépôts en espèces et les dépôts de paiement collectés pendant les livraisons. Elle offre des options pour enregistrer les détails des dépôts, suivre les montants déposés et garantir que les fonds collectés sont correctement rapprochés avec le système de back-office.
