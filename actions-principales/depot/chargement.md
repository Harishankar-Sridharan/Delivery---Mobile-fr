# Chargement

La fonctionnalité de chargement mobile de Nomadia Delivery permet aux utilisateurs de livraison de gérer les statuts des colis et de suivre les activités de chargement. Les utilisateurs peuvent vérifier les colis et les missions avant de commencer leurs tournées afin d’assurer une préparation efficace. Ce flux de travail simplifie la transition entre l’entrepôt et le véhicule.

#### Prise en main

* Application mobile ND installée sur l’appareil.
* Un itinéraire attribué disponible dans l’application.
* Ouvrez l’itinéraire attribué depuis le **Tableau de bord**.

<figure><img src="../../.gitbook/assets/image (105).png" alt="" width="540"><figcaption></figcaption></figure>

* Sélectionnez **Charger mon véhicule** pour démarrer le processus.

<figure><img src="../../.gitbook/assets/image (106).png" alt="" width="540"><figcaption></figcaption></figure>

#### **Aperçu de la fonctionnalité**

* **À charger**: Affiche tous les colis et les missions en attente de chargement.
* **Non chargé**: Liste les colis qui ne sont pas encore dans le véhicule.
* **Chargé**: Affiche les colis qui ont été chargés avec succès dans le véhicule.
* **Bascule des sous-statuts**: Permet de basculer l’affichage pour vérifier les colis chargés et en attente.

<figure><img src="../../.gitbook/assets/image (107).png" alt="" width="540"><figcaption></figcaption></figure>

*   **Paramètres**

    Le **Paramètres** écran vous permet d’effectuer des actions liées aux colis et de personnaliser la façon dont les colis sont affichés dans l’application.

    **Réinitialiser tous les colis**

    Utilisez **Réinitialiser tous les colis** pour rétablir tous les colis à leur état par défaut. Cette option efface le statut actuel des colis et vous permet de recommencer le processus de traitement des colis.

    **Remarque :** La réinitialisation des colis ne peut pas être annulée. Assurez-vous de vouloir effacer le statut actuel des colis avant de continuer.

    **Réduire l’affichage des colis**

    Activez **Réduire l’affichage des colis** pour afficher les colis dans une vue compacte avec moins de détails, ce qui facilite la navigation dans les longues listes de colis.

    * **Activé :** Affiche les colis dans une vue compacte avec un minimum de détails.
    * **Désactivé :** Affiche toutes les informations sur les colis.

    **Astuce :** Activez cette option lorsque vous travaillez avec un grand nombre de colis afin d’améliorer la lisibilité de l’écran.
* **Menu à ellipses**: Ouvre des options d’opérations supplémentaires dans le coin supérieur droit.

<figure><img src="../../.gitbook/assets/image (108).png" alt="" width="540"><figcaption></figcaption></figure>

#### **Procédure : charger les colis par scan**

1. Accédez à la fonctionnalité de scan pour charger rapidement les colis.

<figure><img src="../../.gitbook/assets/image (109).png" alt="" width="540"><figcaption></figcaption></figure>

2. Scannez le code-barres du colis pour mettre à jour automatiquement le statut de chargement.

<figure><img src="../../.gitbook/assets/image (110).png" alt="" width="540"><figcaption></figcaption></figure>

#### Procédure : charger les colis manuellement - si le code-barres physique est illisible ou endommagé

1. Appuyez longuement sur l’entrée du colis pour mettre à jour le statut manuellement.
2. Repérez l’entrée du colis dans la liste si aucun scan physique n’est possible.

<figure><img src="../../.gitbook/assets/image (111).png" alt="" width="540"><figcaption></figcaption></figure>

3. Utilisez les boutons à bascule en bas de l’écran pour indiquer manuellement le statut du colis. Appuyez sur _Charger_ (bouton vert) lors du chargement d’un colis, ou appuyez sur _Ne pas charger_ (bouton rouge) lorsque le colis n’est pas chargé. Cette action permet de traiter les colis manuellement sans scan.

<figure><img src="../../.gitbook/assets/image (112).png" alt="" width="540"><figcaption></figcaption></figure>

4. Le statut du colis est mis à jour sur _Chargé_ dans le Back Office

<figure><img src="../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>

#### Procédure : terminer le flux de chargement

1. Vérifiez tous les colis et machines chargés dans la liste.
2. Sélectionnez **Valider** pour confirmer la fin du chargement.

<figure><img src="../../.gitbook/assets/image (114).png" alt="" width="540"><figcaption></figcaption></figure>

3. Appuyez sur **Confirmer** lorsque la fenêtre contextuelle vous demande de terminer le chargement.

<figure><img src="../../.gitbook/assets/image (115).png" alt="" width="540"><figcaption></figcaption></figure>

**Dépannage : machines inattendues**

Si un colis ou une mission inattendu(e) est scanné(e), l’application l’identifie comme un **Mission inattendue**.

<figure><img src="../../.gitbook/assets/image (124).png" alt="" width="563"><figcaption></figcaption></figure>

#### Conseils de productivité

* 💡 **Réinitialiser la progression**: Utilisez **Réinitialiser tous les colis** dans le menu à ellipses pour effacer tous les statuts et recommencer.
* 💡 **Vue plus épurée**: Utilisez le **Configuration** pour réduire les panneaux d’opérations et obtenir une interface plus épurée.
* ⚠️ **Problèmes de scan**: Effectuez un scan manuel par appui long si le lecteur de code-barres physique tombe en panne.
