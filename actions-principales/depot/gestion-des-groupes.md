# Gestion des groupes

La gestion de groupe permet de regrouper plusieurs processus ou missions dans un conteneur, une palette ou une unité de transport. Cette fonctionnalité aide les répartiteurs à organiser les éléments en entités uniques pour faciliter le suivi du transport. Les utilisateurs peuvent effectuer rapidement le processus de regroupement en scannant les éléments et en les attribuant à des conteneurs spécifiques.

#### Prise en main

* Prérequis : Assurez-vous que le **peut regrouper plusieurs missions** est activé pour vos types de conteneurs.
* Configuration requise : Accès au **Actions principales** menu dans l'application mobile.
* À partir de l' **Actions principales** écran, faites défiler vers le bas pour trouver les options de gestion.
* Appuyez sur **Gestion de groupe** pour ouvrir la fonctionnalité.

<figure><img src="../../.gitbook/assets/image (71).png" alt="" width="540"><figcaption></figcaption></figure>

#### Aperçu de la fonctionnalité

* **Scanner de code-barres**: Utilisez cet outil en bas de l'écran pour identifier les machines.
* **Définir une adresse**: Ce champ vous permet d'attribuer une destination au conteneur.
* **Type de conteneur**: Ce menu déroulant propose des options telles que **Palette**, **Colis**, ou **Pièces**.

#### Mode d'emploi : créer un groupe de machines

1. Ouvrez l' **Gestion de groupe** page depuis le menu principal.
2. Appuyez sur l'icône de scan pour scanner les premières missions.

<figure><img src="../../.gitbook/assets/image (72).png" alt="" width="540"><figcaption></figcaption></figure>

3. Appuyez pour scanner des machines supplémentaires afin de les ajouter au même groupe.

<figure><img src="../../.gitbook/assets/image (73).png" alt="" width="540"><figcaption></figcaption></figure>

4. Appuyez sur la coche une fois toutes les missions scannées.
5. **Facultatif :** Définissez une adresse si vous souhaitez attribuer une adresse différente au conteneur.

<figure><img src="../../.gitbook/assets/image (74).png" alt="" width="540"><figcaption></figcaption></figure>

6. Recherchez une adresse dans la liste d'adresses globale.

<figure><img src="../../.gitbook/assets/image (75).png" alt="" width="540"><figcaption></figcaption></figure>

7. Scannez le conteneur **Code-barres** ou appuyez sur la coche pour continuer.
8. Appuyez sur **Type de conteneur** et sélectionnez l'unité appropriée dans le menu.

<figure><img src="../../.gitbook/assets/image (76).png" alt="" width="540"><figcaption></figcaption></figure>

6. Appuyez sur **Confirmer** pour terminer le regroupement.

Si vous voyez une fenêtre contextuelle « Aucune adresse sélectionnée », le système utilisera le **Agence d'adresse** par défaut.

<figure><img src="../../.gitbook/assets/image (77).png" alt="" width="540"><figcaption></figcaption></figure>

7. Les missions sélectionnées sont regroupées dans un conteneur dans le Back Office.

<figure><img src="../../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>

#### **Dissocier une mission enfant**

1. Sur la **Dissocier** page, appuyez sur l' **Scanner** icône du conteneur.

<figure><img src="../../.gitbook/assets/image (79).png" alt="" width="540"><figcaption></figcaption></figure>

2. Sélectionnez la ou les missions enfants à dissocier et appuyez sur la **coche** icône.

<figure><img src="../../.gitbook/assets/image (80).png" alt="" width="540"><figcaption></figcaption></figure>

3. Le statut mis à jour de la mission peut être consulté dans le Back Office.
4. La ou les missions sélectionnées seront retirées avec succès du groupe.
5. Appuyez sur **Confirmer** pour poursuivre l'opération de dissociation.

<figure><img src="../../.gitbook/assets/image (81).png" alt="" width="563"><figcaption></figcaption></figure>

#### **Conseils de productivité**

* 💡 **Localisation rapide**: Utilisez **Autour de moi** pour filtrer les adresses à proximité de votre position GPS actuelle.
* ⚠️ **Configuration préalable**: Assurez-vous que le **Peut regrouper plusieurs missions** option est activée avant de créer des missions enfants. Ce paramètre permet de regrouper plusieurs missions et de les gérer en tant que missions enfants dans un seul conteneur.
