# Lancement de l'application

Le **Lancement de l'application** l'écran est le point de départ de l'application. Après s'être connectés avec succès, les utilisateurs sont dirigés vers l'interface principale, où ils peuvent accéder à toutes les fonctionnalités disponibles en fonction du rôle et des autorisations qui leur sont attribués. Le menu principal offre une navigation rapide vers les tâches opérationnelles, la gestion des missions, les fonctions de dépôt, les paramètres du compte et d'autres fonctionnalités de l'application, permettant aux utilisateurs de commencer efficacement leurs activités quotidiennes.
