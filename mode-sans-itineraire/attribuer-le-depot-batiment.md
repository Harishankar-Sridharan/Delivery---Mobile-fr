# Attribuer le dépôt / bâtiment

Cette fonctionnalité vous permet d’attribuer un dépôt ou un bâtiment spécifique à un profil utilisateur via l’application mobile. Elle garantit la cohérence des affectations de bâtiments en synchronisant les données entre l’application et le back-office. L’utilisation de cet outil aide les dispatchers à maintenir des registres de localisation précis pour l’ensemble du personnel sur le terrain.

#### Premiers pas

* Identifiants de connexion actifs pour le **Nomadia Delivery** application mobile.
* Accès au portail de gestion du back-office pour vérifier les affectations.

#### Étapes

1. Ouvrez l’application mobile et saisissez vos identifiants de connexion.
2. Saisissez vos identifiants de connexion.&#x20;

<figure><img src="../.gitbook/assets/image (169).png" alt="" width="540"><figcaption></figcaption></figure>

#### Aperçu de la fonctionnalité

* **Aucun dépôt**: S’affiche sur le tableau de bord lorsqu’un utilisateur n’a actuellement aucun bâtiment attribué.
* **Modifier**: Ouvre le menu de sélection pour choisir un bâtiment dans la liste attribuée.
* **Gérer les utilisateurs**: La section du back-office où vous pouvez consulter et confirmer les affectations de localisation des utilisateurs.
* **Emplacement**: Le champ spécifique dans le back-office qui affiche le nom du bâtiment synchronisé.

#### Mode d’emploi : attribuer un dépôt / bâtiment

1. Connectez-vous à l’application mobile.
2. Repérez le **Aucun dépôt** option sur le **Tableau de bord.**
3. Appuyez sur le **Modifier** option située juste sous **Aucun dépôt.**

<figure><img src="../.gitbook/assets/image (170).png" alt="" width="540"><figcaption></figcaption></figure>

4. Consultez la liste des bâtiments attribués à votre compte.
5. Sélectionnez un nom de bâtiment, tel que **Kanal**

<figure><img src="../.gitbook/assets/image (172).png" alt="" width="540"><figcaption></figcaption></figure>

6. Vérifiez que le nom du bâtiment sélectionné apparaît maintenant sur la **Tableau de bord** page.

<figure><img src="../.gitbook/assets/image (173).png" alt="" width="540"><figcaption></figcaption></figure>

#### Mode d’emploi : vérifier l’affectation dans le back-office

1. Accédez au portail du back-office et cliquez sur **Gérer les utilisateurs.**
2. Cliquez sur l’utilisateur spécifique que vous souhaitez vérifier.
3. Repérez le **Emplacement** champ pour confirmer qu’il correspond au bâtiment sélectionné dans l’application mobile.

<figure><img src="../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure>

#### Conseils de productivité

* 💡 **Synchronisation automatique**: Les sélections de bâtiment effectuées dans l’application mobile mettent automatiquement à jour le champ d’emplacement du back-office.
